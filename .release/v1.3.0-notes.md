## What's new in 1.3.0

**Report a bug, properly.** The old "Report a bug" button just fired a blank email. It's now a real form — describe what happened, add steps to reproduce if you have them — and it composes the email for you with your app version and platform included automatically.

**Notification center.** A bell icon in the top bar now keeps a running inbox: any error the app hits, a heads-up when a new release is available on GitHub (checked automatically in the background, throttled to once every 12 hours), and a confirmation every time you send a bug report. Unread count badges the bell; opening it marks everything read.

**New app icon.** Replaced the generic default Capacitor icon with a proper branded icon across every Android density and shape (legacy square/round, adaptive squircle/circle) plus iOS.

**Fixed:** status bar icons and the clock were invisible against the light theme — the app now tells Android which icon color to use, and keeps it in sync if you switch system theme while the app is open.
