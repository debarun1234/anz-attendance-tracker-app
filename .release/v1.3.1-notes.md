## What's new in 1.3.1

**Public holidays are actually red now.** They used to share a muted slate-blue token that read as flat grey in dark theme — barely distinguishable from an empty cell. Public holidays now get their own crimson/rose color, consistent in both light and dark.

**Unmarked days no longer look like holidays.** Fixing the color above surfaced a second problem: unmarked past days already used red too, so a holiday and a logging gap could look identical at a glance. Unmarked (past) cells now get a diagonal hazard-stripe pattern instead of a flat fill — same "needs attention" red, but visually distinct from a holiday the moment you look at the calendar grid.

**Updating is one tap now.** "Check for updates" used to just point you at the GitHub release page to download and install manually. It now downloads the new APK in the background and hands it straight to Android's installer — you just confirm the install. (First time, Android will ask you to allow "install unknown apps" for Office Ledger; approve that once and future updates go straight through.)

**Update alerts reach your notification panel, not just the in-app bell.** The background check that already ran quietly on launch was only ever surfacing inside the app's own notification center. It now also fires a real Android notification, the same way day-logging reminders already do — so you'll know about a new release even with the app closed.
