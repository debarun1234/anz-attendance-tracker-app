## What's new in 1.5.2

**A clearer, greener "logged" stamp.** The full-screen GPS celebration reveal now sits on a deeper, greener scrim so the "Present — logged" moment reads clearly against either theme, instead of a subtle dark tint.

**Straight answers about updates.** "Check for updates" now tells you upfront how your version actually updates: the Android app downloads and installs the new APK in one tap, same as before. The installed web app can't do that — there's no installer to hand a file to — so it now says exactly what happens instead: it fetches the new version in the background and swaps over on its own within a few seconds, and if it hasn't caught up yet, fully closing it (swiping it away from recent apps, not just switching away) and reopening once is normally all it takes. The web app also nudges itself to check the moment you tap Update, and reloads on its own the instant the new version actually takes over.
