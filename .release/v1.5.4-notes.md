## What's new in 1.5.4

**Faster PWA update detection.** The installed web app now checks for a new version every time it opens, instead of waiting on the browser's own occasional check timing. Combined with the auto-reload added in 1.5.2, this shortens how long anyone stays on stale code — and none of it ever needs a reinstall; fully closing and reopening once is the ceiling of what's ever required.

**"Updated to vX.X.X" confirmation.** The app now notices when it's running a newer version than last time you opened it and says so with a quick toast — closing the loop on "did that actually work?", since the web app has no install-confirmation screen the way Android's package installer does.

**One honest caveat.** If you're coming from a version installed well before 1.5.2, the very first update past this point still needs that one manual close-and-reopen — a service worker can only start auto-reloading once the page carrying that logic has actually loaded once. Every update after that lands on its own.
